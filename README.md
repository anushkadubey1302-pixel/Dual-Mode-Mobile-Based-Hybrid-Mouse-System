# 🖱️ Dual-Mode Mobile-Based Hybrid Mouse System

## 📌 About the Project

The Dual-Mode Mobile-Based Hybrid Mouse System is a project designed to enable wireless laptop control through a smartphone. It currently uses Wi-Fi for communication, while Bluetooth connectivity is under development. The project aims to bring essential laptop controls into a convenient mobile interface.

## 🎯 Objective

To develop a mobile-based hybrid mouse system that enables users to control their laptops wirelessly through a smartphone using Wi-Fi and Bluetooth connectivity.

## ✨ Features

### Implemented

* Wi-Fi-based communication between a smartphone and laptop.
* Python-based mouse-control functionality.
* Smartphone interaction through a web interface.

### Available Modes

* **Mouse Mode** — Control laptop mouse functions through a smartphone.
* **Keyboard Mode** — Access keyboard-related controls.
* **Media Control Mode** — Access media playback controls.
* **Presentation Mode** — Access presentation-related controls.
* **System Mode** — Access system-related controls.

### Connectivity

* **Wi-Fi:** Currently working for communication between the smartphone and laptop.
* **Bluetooth:** Under development.

### Under Development

* Bluetooth connectivity.

### Planned Enhancements

* Keyboard controls.
* Media playback controls.
* Presentation controls.
* Additional system controls.
* Improved connection handling and user experience.

## 🛠️ Technologies Used

* **Python** — Application logic and desktop control.
* **Flask** — Web application framework.
* **PyAutoGUI** — Mouse and keyboard automation.
